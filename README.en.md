# 📖 About

**Apenas Pastel** is a modern and interactive web application built with Next.js 15, React 19, TypeScript, and Tailwind CSS for an artisanal Brazilian pastel shop based in Belo Horizonte, Brazil. The project faithfully translates the Figma design (both mobile and desktop viewports) into a seamless digital ordering experience, featuring real-time batch statuses, customizable toppings, free-shipping goals, light/dark themes, and direct checkout via WhatsApp.

# 📋 Motivation

Created as the rebirth of an old high school project.

# ✨ Features & Functionality

- **Responsive & Mobile-First Design**: Seamless layout transition from 390px mobile viewports up to ultrawide desktop monitors.
- **Vector Fork-Crimped Pastry Border**: Custom SVG section divider replicating traditional Brazilian street-market pastel edges.
- **Fresh From the Fryer Section**: Horizontal carousel of live frying batches with real-time pulsing indicators.
- **Tactile Bottom Sheet & Modal (`vaul`)**:
  - Add-on toppings (stuffed crust, extra cheese, vinaigrette).
  - Special kitchen instructions field.
  - Quick nutritional facts: prep time, spiciness, and servings.
  - Dynamic quantity stepper.
- **Interactive Cart & Free Delivery Calculator**:
  - Animated progress bar tracking eligibility for free delivery.
  - Segmented toggle between home delivery and counter pickup.
  - Upsell carousel with beverage and side recommendations.
  - Toast alerts with undo support via `sonner`.
- **Streamlined WhatsApp Checkout**:
  - Step-by-step modal: personal info, delivery address, and payment method.
  - Formatted order summary sent directly to WhatsApp.
- **Celebratory Order Confirmation**: Interactive confetti explosion powered by `canvas-confetti` alongside live status stepper.
- **Light & Dark Themes**: Smooth, flash-free theme switching matching Figma screen 06 via `next-themes`.
- **Full Internationalization (i18n)**: Seamless language switcher supporting Portuguese and English.

# 💻 Getting Started

### Requirements

- [Node.js](https://nodejs.org)
- [npm](https://www.npmjs.com)

### Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/BGLuis/apenas-pastel.git
   ```

2. Enter the project directory:

   ```sh
   cd apenas-pastel
   ```

3. Install dependencies and start the development server:

   ```sh
   npm install
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
